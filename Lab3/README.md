This file contains 20,000 student records, each representing a combination of academic behavior, lifestyle factors, learning resources, and exam conditions that influence a student's final exam score. The dataset is structured to be easy to read and understand, without requiring any technical background.

Each row includes:

A unique student ID

Basic demographic information such as age, gender, and course of study

Details about the student’s study habits, including daily study hours and class attendance

Lifestyle-related information such as sleep duration and sleep quality

Access to resources like internet availability

Academic environment indicators such as facility rating

The difficulty level of the exam attempted

The final exam score, ranging from 0 to 100

The dataset is clean, consistent, and contains no missing values. All values fall within realistic ranges, and the dataset is ready to be explored, analyzed, or visualized. It is designed for general educational research, academic insights, comparison of study habits, or performance-related analysis.
